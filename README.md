# MiniMarket "EL GUARDIAN"

## Proyecto Áulico – DSHI-314

### Descripción del proyecto
MiniMarket "EL GUARDIAN" es un pequeño negocio dedicado a la venta de productos de consumo diario. El proyecto consiste en desarrollar una aplicación móvil que permita organizar y facilitar el control de los productos, las ventas y el inventario del establecimiento.

### Problema identificado
El negocio lleva el registro de sus productos y ventas de manera manual, lo que dificulta consultar las existencias, controlar los productos disponibles y mantener organizada la información de las ventas.

### Objetivo general
Desarrollar una aplicación móvil para mejorar el control de productos, ventas e inventario del MiniMarket "EL GUARDIAN".

### Funcionalidades principales
- Consulta de productos y precios.
- Registro de ventas.
- Control de inventario.
- Consulta de existencias disponibles.

### Tecnologías previstas
- Android Studio.
- Kotlin.
- RecyclerView.
- GitHub.
